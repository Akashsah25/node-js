# Full Stack Web Application — Node.js + React

A production-ready full stack application built with Node.js, Express, and React.

## Tech Stack
- **Backend:** Node.js, Express.js
- **Frontend:** React.js
- **Database:** MongoDB
- **Auth:** JWT Authentication
- **Tools:** REST API, Prettier

## Features
- User authentication (Register/Login)
- REST API with full CRUD operations
- Clean folder structure (MVC pattern)
- Ready for deployment

## Setup
npm install
npm start
